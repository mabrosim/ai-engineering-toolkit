# Security Policy

## Scope

This repository contains AI agent definitions, skills, and workflow templates.
It does not include executable application code, network services, or data stores.

## Reporting a Vulnerability

If you discover a security issue — including sensitive information accidentally
committed, prompt injection risks, or unsafe default configurations — open a
public issue containing only a sanitized notice that a private reporting route
is needed. GitHub private vulnerability reporting is the planned confidential
route, but it is not yet configured and verified for this repository.

Do not include vulnerability details, secrets, private identifiers, internal
paths or URLs, or proprietary context in public issues.

## Expectations

- Reports will be reviewed as maintainer availability permits.
- Confirmed issues will be prioritized according to severity.
- Credit will be given to reporters unless anonymity is requested.

## Safe Content Policy

All content in this repository is designed to be NDA-safe and free of secrets.
See [docs/public-safety.md](docs/public-safety.md) and
[validation/nda-safety-checklist.md](validation/nda-safety-checklist.md).
